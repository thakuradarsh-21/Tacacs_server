# TACACS+ Server Setup on Ubuntu

This repository contains a complete setup guide and configuration for deploying a **TACACS+ authentication server** on **Ubuntu Linux**.  
The project is intended for network authentication, authorization, and accounting (AAA) use cases in enterprise environments.

---

## 📌 Features

- TACACS+ server installation on Ubuntu
- Secure AAA authentication for network devices
- Centralized user management
- Role-based access control
- Logging and accounting support
- Compatible with routers, switches, firewalls, and network appliances

---

## 🛠️ Prerequisites

Before starting, ensure you have:

- Ubuntu 20.04 / 22.04
- Root or sudo privileges
- Basic knowledge of Linux command line
- Network device supporting TACACS+ (Cisco, Juniper, Fortinet, etc.)
